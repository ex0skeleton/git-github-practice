# My Git Practice

A deliberately small website for learning Git and GitHub from VS Code's terminal.
No packages, build tools, or server are required. Open index.html in your browser.

## Files

- index.html: page content and structure.
- css/style.css: colors, spacing, and appearance.
- js/script.js: button behavior.
- .gitignore: rules for files Git should normally leave untracked.
- README.md: project introduction shown on GitHub.
- LEARNING-PLAN.md: our lesson order.

This folder does not include a Git repository yet. We will create one together.
GitHub Actions will be added in a later lesson so we can watch the change happen.
